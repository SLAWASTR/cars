# 🏎️ Автотека (CarDex)

> **Премиальное веб- и Android-приложение для автоспоттинга и личной коллекции автомобилей.**  
> Сделано специально для **Ragazzo_15** / **Ваня** & **slawastr**.

🌐 **Онлайн веб-версия (GitHub Pages)**: [https://slawastr.github.io/cars/](https://slawastr.github.io/cars/)  
📱 **Скачать Android APK (Релиз)**: [Releases](https://github.com/SLAWASTR/cars/releases)

---

## ✨ Ключевые возможности

- 🖤 **Absolute Carbon AMOLED**:
  - Истинный чёрный `#000000` для максимальной экономии батареи на OLED/AMOLED дисплеях.
  - Полностью исключены белые баги кнопок и системных браузерных компонентов.
  - Адаптивная синхронизация цвета статус-бара и панели навигации Android.
  - Альтернативная контрастная светлая тема (Showroom Light).
  - Кастомный редактор 4-х ключевых цветов и культовые автомобильные пресеты: *Rosso Corsa, Lava Orange, WRX Blue, British Racing Green, Giallo Modena, Midnight Purple*.

- 👤 **Профиль коллекционера и автоспоттера**:
  - **Динамический дефолтный ник**:
    - **Ragazzo_15** — в веб-версии на GitHub Pages.
    - **Ваня** — в нативном Android APK приложении.
  - Кастомная смена аватара с камеры или галереи, редактирование био.
  - Привязка социальных профилей: **Drive2, Telegram, YouTube, VK, личный сайт/блог**.
  - Подсчёт суммарной мощности спотов (л.с.), количества марок, суперкаров и личного гаража.

- 🏎️ **«Мой личный гараж»**:
  - Отдельный раздел для хранения собственных автомобилей, проектов тюнинга, корчей или машин мечты с полноэкранным просмотром.

- 🗺️ **Интерактивная карта спотов**:
  - Карта OpenStreetMap / Leaflet с кастомными неоновыми пинами с логотипом марки и превью.
  - Быстрое построение маршрута к точке спота в Яндекс Картах и Google Maps.

- 📸 **Автоматическое чтение EXIF и GPS**:
  - При загрузке оригинального фото дата съёмки и GPS-координаты автоматически извлекаются из EXIF метаданных и привязываются к споту с обратным геокодированием адреса.

- 🎴 **Gran Turismo Trading Card**:
  - В один клик генерация коллекционной карточки автомобиля 1200x800 px (PNG) с логотипом, спидометром, техническими характеристиками (л.с., КПП, привод, звук выхлопа) и ником споттера.

- ✈️ **Telegram & Экспорт**:
  - Мгновенная отправка спота в Telegram.
  - Полный экспорт и импорт базы в JSON (включая все фото Retina-качества в IndexedDB).

- ☕ **Поддержка авторов**:
  - Быстрый донат разработчикам через [Ozon Банк / СБП](https://finance.ozon.ru/apps/sbp/ozonbankpay/01a155d9-e962-7ffe-aa0c-ac329362226c).

## 🛠️ Стек технологий

- **Frontend**: Vanilla ES6+ HTML5/CSS3 (Grid, Flexbox, CSS Variables), IndexedDB API, HTML5 Canvas 2D Engine, Geolocation API, Binary EXIF Parser.
- **Картография**: Leaflet 1.9.4 (автономная локальная оффлайн-сборка) + OpenStreetMap Nominatim.
- **Android**: Java 17, WebView, WebChromeClient (камера, выбор нескольких файлов, геолокация), JavaScriptInterface (`AndroidBridge`), Android Support API 24–34.
- **CI/CD**: GitHub Actions (GitHub Pages Deploy + Gradle 8.2 Release APK Builder).
